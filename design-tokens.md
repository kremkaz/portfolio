
## Статус файла

Часть 1 (нейтральная база — фон/текст/бордеры от shadcn) заполнена по факту генерации визарда `shadcn init` (base-vega). Часть 2 (акцент + структура карточек) выверена напрямую по файлу Figma "Portfolio" (node 42:3076, коннектор Figma MCP) — значения взяты из сгенерированного кода и переменной `portfolio/primary`, это источник истины, а не пиксельный замер скриншота.

## Шрифт

- Everywhere — **Inter**. В самом Figma-файле часть текста (крупные заголовки карточек, чипы навыков/футер) набрана шрифтом **Onest** — по решению не заводим второй шрифт, весь Onest/Inter Tight сводим к Inter с соответствующим начертанием (Bold/SemiBold/Medium/Black — у Inter как variable-шрифта это просто разный font-weight).

## Цвет — акцент (сверено с Figma, файл Portfolio)

`--primary` — единственная настоящая Figma-переменная в файле (`portfolio/primary`). Остальное — использованные в макете raw-значения (не заведены как переменные в самой Figma), но подтверждены по коду:

```css
--primary: #005170;                    /* Основной цвет (с 2026-10 — #005170, раньше #000FDC из Figma-переменной portfolio/primary). Заливка pill hard-скиллов, кнопки "Смотреть кейсы", текст CV/Связаться, бейджи категорий, ссылка "Открыть кейс" — везде 100%, НЕ приглушённый */
--primary-tint: rgb(0 81 112 / 0.07);  /* фон бейджей категорий (B2B/DESKTOP/...), фон тегов в "Записках о дизайне" */
--primary-border: rgb(0 81 112 / 0.25); /* граница outline-кнопок CV/Связаться (2px) */
--primary-hover: color-mix(in oklch, var(--primary) 80%, black); /* ховер всего, что окрашено в primary: заливки, текст, иконки (у <img>-иконок — brightness(0.8)). Только темнее, без прозрачности: primary/90 и плашки primary/[0.08] на ховере уводят цвет в голубой */

--secondary: #FF2D85;        /* soft-скиллы, solid pill, ярко-розовый (не #EE6B9E — старое значение было неточным замером) */
--secondary-tint: rgb(255 45 133 / 0.07); /* фон тегов категории B2B/UX во втором блоге */

--foreground-strong: #111212;  /* h1 имя, заголовки секций */
--foreground-card-title: #0A0A0A; /* заголовки карточек кейсов/блога — чуть темнее foreground-strong */
--foreground-muted: #666666;   /* описание в карточке кейса */
--foreground-subtle: #ACACAC;  /* подзаголовок кейса */
--foreground-faint: #AAAAAA;   /* год, мета блога (дата/время чтения) */
--foreground-disabled: #A7A7A7; /* статус "В разработке" у кейса in progress */
--foreground-title-disabled: #6D6D6D; /* заголовок карточки кейса in progress */
--foreground-tag-disabled: #C8C8C8; /* текст тегов у кейса in progress (фон тега — rgb(0 0 0 / 0.07)) */

--border-subtle: #E8E8EC;    /* граница карточек кейсов/блога */
--background: #FFFFFF;
--background-section: #F7F7F9; /* фон секции "Записки о дизайне" */
--background-section-hover: #EEEEF1; /* ховер серых кружков в шапке (язык, Telegram, почта) и карточки «Следующий кейс» */
--background-footer: #242B2F;  /* тёмная нижняя плашка с копирайтом/контактами */

/* Статус-бейдж "Открыта к офферам" — отдельная семантика, не завязана на primary/secondary */
--status-available-bg: rgb(0 255 13 / 0.12);
--status-available-border: rgb(6 121 0 / 0.22);
--status-available-dot: #00CC03;
--status-available-text: rgb(0 96 0 / 0.9);
```

Важно: токен `--primary-70` из старой версии этого файла — **не существует** в реальном макете, это была ошибка пиксельного замера. Everywhere, где раньше подразумевался приглушённый primary (текст бейджей, ссылка "Открыть кейс"), в реальности используется 100%-й `--primary`.

## Нейтральная база (shadcn)

Сгенерировано визардом `shadcn init` (стиль `base-vega`, база компонентов — Base UI, иконки — Lucide, шрифт пресета — Inter). Значения лежат в `app/globals.css`, тут — для справки, не дублировать руками при правках.

```css
  --foreground: oklch(0.145 0 0);
  --card: oklch(1 0 0);
  --card-foreground: oklch(0.145 0 0);
  --popover: oklch(1 0 0);
  --popover-foreground: oklch(0.145 0 0);
  --primary: oklch(0.205 0 0);
  --primary-foreground: oklch(0.985 0 0);
  --secondary: oklch(0.97 0 0);
  --secondary-foreground: oklch(0.205 0 0);
  --muted: oklch(0.97 0 0);
  --muted-foreground: oklch(0.556 0 0);
  --accent: oklch(0.97 0 0);
  --accent-foreground: oklch(0.205 0 0);
  --destructive: oklch(0.577 0.245 27.325);
  --border: oklch(0.922 0 0);
  --input: oklch(0.922 0 0);
  --ring: oklch(0.708 0 0);
  --radius: 0.625rem;

```

Решено: `--primary` в `app/globals.css` переопределён на брендовый `#005170` (изначально был `#000FDC` — Figma-переменная `portfolio/primary`; цвет сменён по решению Евгении, Figma пока не обновлена), `--primary-foreground` остаётся белым. `--secondary` из shadcn (нейтральный светло-серый, используется под капотом в компонентах типа Button variant="secondary") НЕ трогаем — он не то же самое, что брендовый розовый `#FF2D85` из раздела выше: розовый — это только заливка soft-скилл-пилюль, отдельный кейс, не общий UI-токен кнопок. Для розовых пилюль стилизуем напрямую (`bg-[#FF2D85]` / кастомный класс), а не через `--secondary`.

## Компонент: карточка кейса

Структура (сверху вниз), по скриншоту главной страницы:

1. **Контейнер** — белый фон, `border-radius` заметный (визуально ~16–20px), тонкая едва заметная граница (`--border-subtle`), мягкая тень, `overflow: hidden` (чтобы картинка сверху обрезалась по радиусу)
2. **Медиа** — фото-мок устройства на тёмном фоне, на всю ширину карточки, верхние углы скруглены как у контейнера, нижние — прямые
3. **Контент-блок** (паддинг ~24px):
    - **Ряд тегов** — flex, gap между пилюлями, каждая: `--primary-05` фон, `--primary-70` текст, bold, мелкий кегль, form-фактор pill (`border-radius: full`)
    - **Заголовок** — bold, ~20–22px, `--foreground-strong`, до 2 строк
    - **Подзаголовок** (формат "Название — короткое описание") — `--foreground-subtle`, обычный вес, отступ сверху небольшой
    - **Описание** — `--foreground-muted`, отступ сверху больше, 2–3 строки
    - **Разделитель** — тонкая горизонтальная линия на всю ширину блока
    - **Футер** — flex, justify-between: слева год (`--foreground-subtle`), справа ссылка "Открыть кейс ↗" (`--primary-70`, bold, со стрелкой)
4. **Вариант "в разработке"** (третья карточка) — год заменён на "soon", ссылка заменена на нейтральный неактивный текст "В разработке" без стрелки и акцентного цвета — визуально приглушённое/disabled-состояние

## Компонент: блок навыков

- Заголовок H2, bold, `--foreground-strong`, по центру
- Три колонки (hard / soft / tools) без разделителей, на десктопе в ряд, на мобилке друг под другом; всё выровнено по левому краю
- Над каждой колонкой — мелкая подпись строчными буквами, `--foreground-subtle`
- Пилюли: `flex-wrap`, по левому краю, ширина по контенту, без переноса текста внутри одной пилюли. Стиль как у тегов в карточке кейса (полупрозрачная плашка + цветной semibold текст), размер прежний (высота 40px, 14px текст)
    - hard: фон `--primary-tint`, текст `--primary`
    - soft: фон `--secondary-tint`, текст `--secondary`
    - tools: фон `rgb(0 0 0 / 0.07)`, текст `--foreground-strong` (временно, цвет ещё не выбран)
- Без иконок, только текст в пилюлях

## Компонент: кнопка "Связаться"

- Pill-форма, прозрачный фон, тонкая светлая индиго-граница, текст `--primary` (100%), bold, по центру

## Шаблон страницы кейса (сверено с Figma, node 159:19, кейс Vecta)

Общая система отступов/типографики — та же, что на главной (`max-w-4xl`, `text-3xl sm:text-4xl font-semibold tracking-tight` для H2, `gap-20 sm:gap-28` между крупными блоками). Специфичное для кейс-страниц:

- **Hero кейса** — единственное место в проекте с цветным (не белым) фоном: заливка `--primary` (#005170). Белый текст, декоративное радиальное пятно в углу. Карточка меты (Роль/Срок/Тип + теги инструментов) — `bg-white/10 border-white/25`.
- **StageLabel** (нумерация "00 — Контекст и задача") — номер `text-primary/40`, тонкая линия `bg-primary/35` шириной 28px, лейбл `text-primary uppercase tracking-widest text-xs` — тот же язык, что теги кейс-карточек на главной, только без фона-плашки.
- **Callout "Задача:"** — в Figma был не по токенам (случайный зелёный `#e3fff3`/`#97cab3`) — заменён на `bg-primary/[0.06]` + `text-primary`, по системе.
- Кейс-страницы переиспользуют `SiteHeader`/`SiteFooter` с главной — навигация должна быть одинаковой по всему сайту.
- Компоненты лежат в `components/case-study/*`, контент — в `content/cases/<slug>.ts` (типы в `content/cases/types.ts`) — при добавлении Tanuki/сна использовать ту же структуру.
